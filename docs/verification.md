# Проверка tenantdesk

Проверено 10 сентября 2026 года локально на Docker Desktop, ARM64.
Это результаты воспроизводимых тестов и демонстраций, без заявления о
реальной коммерческой нагрузке.

| Проверка | Результат |
|---|---|
| Ruff lint / format | Пройдены |
| uv.lock | Согласован с pyproject.toml |
| PostgreSQL integration tests | **20 passed in 2.52s** |
| Docker Compose | API, БД и фоновые процессы healthy |
| Live HTTP smoke | Пройден |
| Seed дважды | Успешно, уникальные демонстрационные записи сохранены |
| Runtime image | pytest и Ruff отсутствуют |
| OpenAPI snapshot | Совпадает с запущенным API |

- Две компании: чужой документ недоступен через ID и подмену заголовка.
- Прямой SQL без tenant-фильтра ограничен PostgreSQL RLS.
- Проверен возврат одного и того же соединения в пул после commit и rollback.
- Проверены квоты при конкурентных запросах и конфликт одинаковых If-Match.
- Проверены восстановление документа, изолированный экспорт и отзыв членства.
- Запись, ожидавшая блокировку, отклоняется после отзыва прав.
- API работает под `tenantdesk_app`, exporter под отдельной ролью без BYPASSRLS.
